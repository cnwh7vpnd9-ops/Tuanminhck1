Kiểm tra kết nối GitHub thành công.

## Website thuyết trình Vật lý 10

Bài 9 — Chuyển động thẳng biến đổi đều (Kết nối tri thức).

- **Mở bài thuyết trình:** https://cnwh7vpnd9-ops.github.io/Tuanminhck1/
- **Mã nguồn:** [index.html](./index.html)

Trang trình chiếu có hiệu ứng chuyển slide, nhân vật minh họa, công thức, ví dụ giải mẫu, đồ thị v–t và câu hỏi trắc nghiệm tương tác. Dùng phím mũi tên trái/phải để chuyển slide. Để xuất bản website bằng GitHub Pages, vào Settings → Pages và chọn nhánh `main`, thư mục `/(root)` nếu Pages chưa được bật.
